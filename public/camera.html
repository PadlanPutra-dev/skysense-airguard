Tentang Project

Deskripsi Produk

SkySense Weather Station adalah sistem pemantauan lingkungan berbasis IoT yang cerdas. Alat ini mengintegrasikan sensor presisi tinggi untuk memberikan data cuaca real-time, analisis tren, serta sistem peringatan dini yang dapat diakses dari mana saja.

Fitur Unggulan

Monitoring Cuaca

Menampilkan data suhu, kelembaban, tekanan udara, dan curah hujan secara langsung.

Prediksi Cuaca

Melakukan estimasi kondisi cuaca beberapa jam / hari ke depan berdasarkan data historis.

Dashboard Web Interaktif

Data ditampilkan dalam bentuk grafik dan indikator yang mudah dipahami.

Penyimpanan Data Historis

Data cuaca disimpan pada database untuk analisis jangka panjang.
